# Movie Explorer

Movie Explorer is a web application built with Angular for discovering and searching movies.

## Tech Stack

- Angular
- TypeScript
- HTML
- CSS
- RxJS

## Current Status

Sprint 1 completed:

- Initial Angular project setup
- Application routing
- Home page
- Search page
- Movie detail route
- Shared navigation
- Shared footer
- Responsive base layout

## Planned Features

- Popular movies
- Trending movies
- Upcoming movies
- Movie search
- Movie details
- Cast information
- Filters and pagination
- Responsive design
- TMDB API integration
